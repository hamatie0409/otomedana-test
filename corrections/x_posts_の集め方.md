# キャラクター紹介Xポストの集め方

渡してもらうのは **投稿のURLだけ** でよい。cid も vid も書かなくていい。
どの作品のどのキャラかは、投稿者と本文からスクリプト側で判定する。

埋め込みコードもコピーしなくてよい。X の埋め込みHTMLは
`publish.x.com/oembed` から認証なしで取れるので、URLさえあれば生成できる。
あとから表示方法を変えたくなっても、集め直しは要らない。

## 手順

### 1. 何を探すかを出す

```bash
python3 scripts/x_posts.py sheet --limit 10
```

未収集のキャラだけを、作品ごとに優先順（人気順）で出す。
各行に X の検索URLが付いているので、上から順に開けばよい。

公式アカウントが未特定の作品は「探す」のURLが出る。分かったら
`corrections/x_accounts.tsv` に1行足す。1作品につき1回だけの作業。

### 2. URLを控える

検索結果から、そのキャラを紹介している投稿の**リンクをコピー**して、
テキストファイルに貼っていく。**書式は問わない。** 1行1URLでも、
メモが混ざっていても、`?s=20` が付いていてもよい。

```
ピオフィオーレ
https://x.com/pf_otomate/status/936530775264059392
https://twitter.com/pf_otomate/status/936530104255102976?s=20

BUSTAFELLOWS
https://x.com/BUSTAFELLOWS/status/1659435043977334786
```

**どれを採るか。** 良いものから順に、

1. **プロフィール型** —「【キャラクター紹介】名前（CV.○○）年齢：18歳 …」のように
   人物の説明が入っているもの。データベースサイトには一番合う
2. **誕生日ポスト** — 描き下ろしイラストが付くので見栄えはよい
3. その他

1人につき複数あってよい。載せる1件はスクリプトが上の順で選ぶ。
迷ったら両方入れておけばよい。

### 3. 読み込む

```bash
python3 scripts/x_posts.py intake urls.txt
python3 scripts/x_posts.py verify
```

`intake` が投稿者と本文を見てキャラに割り当て、`verify` が
実在・公式アカウント・本文のキャラ名を確かめる。通ったものだけが
`corrections/x_posts.tsv` に入り、怪しいものは `_review_x.tsv` に回る。

### 4. 見た目を確かめる

```bash
python3 scripts/x_posts.py preview c94428 --out /tmp/x
python3 scripts/x_posts.py preview --work v29661 --out /tmp/x
```

## 気をつけること

**公式アカウント以外は入れない。** ショップ（K-BOOKS など）やファンの投稿、
舞台版・アニメ版の別アカウントは `verify` が弾く。アニメ版など
「別だが公式」を使いたい場合は `x_accounts.tsv` の account 列に
空白区切りで並べて書く。

**自動化された巡回はXの規約違反にあたる。** 手で辿るぶんには問題ないが、
スクリプトで大量に速く回すとアカウントに制限がかかる。

**取りこぼしは避けられない。** 公式が投稿していても検索に出ないことがある。
埋まらない人は空のままでよく、その場合キャラページは今までどおり
代表作のパッケージを出す。
