# デザインの出どころ

このディレクトリは、`docs/v2/` を作るときに参照した **Claude Design のプロジェクト**
"Otome Index"（`claude.ai/design/p/217630b8-7809-4125-9b08-f471b3b3374f`）の控え。
実装の答え合わせ用に置いてあるだけで、サイトの生成には使っていない。

| ファイル | 何か |
|---|---|
| `_ds/styles.css` | Modernist デザインシステムの元CSS。角丸ゼロ・2px罫・左揃えの規則がここに入っている |
| `Otome Product Page.dc.html` | 作品ページの別案（青系のテーマ・full-bleedヒーロー）。今回は未採用 |

## 与えられていた画面

- `Otome Home` / `Otome Home Mobile` — トップ（検索・カテゴリ・発売予定・新着）
- `Otome Game Detail` / `Otome Game Detail Mobile` — 作品ページ（購入導線・キャラ・好み一致）
- `Otome My Page` — MY棚（所持/欲しい・進捗・メモ・属性集計）
- `Otome Product Page` — 作品ページの別案（未採用）

## 実装で意図的に変えたところ

1. **モバイル版を別ページにしていない。** デザインは 430px 幅の別アートボードだが、
   同じHTMLをCSSの折り返しで出す。URLが1本で済み、生成数も倍にならない。
2. **`.grayscale` を作品画像に掛けていない。** デザインの「写真は白黒で刷る」は
   モックでは斜線プレースホルダに掛かっていた。実物のパッケージを白黒にすると
   商品が判別できなくなるため、画像はカラーのまま。斜線プレースホルダにだけ残した。
3. **DBに無い要素は置いていない。** スクリーンショット・イベントCG・店舗特典・送料・
   レビュー引用（「週刊ゲームレビュー」など実在しない媒体名）は出典が無いので作らない。
4. **トップのヘッダを全ページ共通にした。** デザインのトップにはヘッダが無かったが、
   下層から戻る導線が要るため統一した。
